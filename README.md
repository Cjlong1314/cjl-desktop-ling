# 灵

桌面虚拟人物：透明置顶的 Live2D 伙伴，用 MiniMax-M3 聊天，并在本地记住你的喜好。

## 运行

```bash
npm install
npm run dev
```

第一次打开后，在设置里粘贴 MiniMax API Key。国内默认接口是 `https://api.minimaxi.com/v1`，模型 `MiniMax-M3`。

Key 只保存在本机用户目录，并用系统加密（Windows DPAPI），不会写入项目文件。

## 使用

- 单击人物：打开 / 收起聊天
- 拖动人物：移动窗口
- 右键：聊天、设置、隐藏、退出
- 系统托盘：显示、设置、退出
